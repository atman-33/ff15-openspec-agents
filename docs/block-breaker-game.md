以下の要件を満たす「ブロック崩しゲーム」を実装してください。

## 概要
- 非常にシンプルなブロック崩しゲームを作成する
- TypeScript で開発する
- トランスパイル後の JavaScript を GitHub Pages にデプロイ可能な構成にする

## 技術スタック
- TypeScript
- React
- React Router v7
- ビルドツールは一般的なもの（例: Vite）を使用してよい

## アプリ要件
- 1ページ構成で問題ないが、React Router v7 を必ず使用すること
  - 例: `/` にゲーム画面を配置
- Canvas またはシンプルな DOM 操作でブロック崩しを実装する
- 以下の最低限の要素を持つこと
  - パドル（左右移動）
  - ボール
  - 複数のブロック
- ゲームオーバーやクリア判定は簡易的でよい
- 見た目は簡素で構わない（CSS は最小限でOK）

## 実装方針
- ロジックはできるだけシンプルに保つ
- 初学者が読んでも理解できる構成を意識する
- 不要な最適化や複雑な設計はしない

## 成果物
- プロジェクト構成（ディレクトリ構造）
- 主要なソースコード（TypeScript / React）
- GitHub Pages にデプロイするための手順
  - ビルド方法
  - `base` / `homepage` 設定の注意点
- README.md 用の簡単な説明文

## 注意
- 「とりあえず動く」レベルで十分
- OpenSpecのドキュメントは、全て日本語で記述すること
